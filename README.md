# Web Paintings

A frontend web development project created to practise building a simple image gallery using **HTML and CSS**.

## Overview

The project focuses on presenting a collection of paintings through a structured webpage layout, with emphasis on:

* HTML page structure
* CSS styling
* Image presentation
* Layout and spacing
* Basic responsive web design

## Technologies

* HTML5
* CSS3

## Purpose

This project represents an earlier stage of my web development learning journey and helped build foundational frontend development skills.

My current focus has expanded into **software engineering, quality assurance, and test automation**, with technologies including Python, JavaScript/TypeScript, Playwright, Selenium, SQL, and API testing.
